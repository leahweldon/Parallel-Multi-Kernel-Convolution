# Authorship, sources and archival scope

This repository preserves a **2023–2024 CSU33014 Concurrent Systems I team project** by **Faith Olopade, Darius Pop and Leah Weldon** at Trinity College Dublin.

## Sources

- `src/conv-harness.c`: from the group-assignment, containing the collaborative `student_conv()` implementation and the harness/reference originally authored by **Dr David Gregg (March 2022, revisions through version 1.7)**. The three team members' university email addresses and student numbers have been removed from the public header.
- `docs/original-group-report-public.pdf`: the original team report. Only the title-page author contact details and student numbers have been redacted/replaced with contributor names. Its narrative and historical claims have not been rewritten.
- `results/historical-benchmarks.csv`: manual transcription of the 13 rows visible in the provided `Runtimes.png` and report table. Calculated ratios use the recorded integer times, rounded to two decimals.
- Build instructions, repository documentation and small-configuration checking script: added for preservation and easier inspection.
